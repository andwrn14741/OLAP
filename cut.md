# Что не входит в проект

## 1. Реальное обогащение из внешних API

**Что:** VIN-декодер, каталоги запчастей, марки/модели авто.  
**Почему нет:** платные ключи, отдельный стек интеграций.  
**Цена ошибки:** нельзя построить отчёт «продажи по маркам авто».

## 2. Возвраты и брак

**Что:** `fact_returns` и метрика «оборот без возвратов».  
**Почему нет:** в сырье З01 возвратов нет, искусственные данные исказят бизнес-смысл.  
**Цена ошибки:** метрика «оборот» — валовая, не чистая.

## 3. Кластер ClickHouse, шардирование, репликация

**Что:** ReplicatedMergeTree, распределённые таблицы.  
**Почему нет:** учебный стенд — один узел в Docker; кластер требует ≥ 3 машин.  
**Цена ошибки:** нет проверки отказоустойчивости; для 20 000 строк это не критично.

## 4. Стриминг через Kafka

**Что:** потоковая загрузка «источник → Kafka → CH».  
**Почему нет:** задание — батчевая загрузка из файлов (см. FAQ).  
**Цена ошибки:** данные обновляются не в реальном времени.

## 5. ML-модель прогноза спроса

**Что:** предсказание спроса по SKU.  
**Почему нет:** тема курса — OLAP, не ML (см. FAQ).  
**Цена ошибки:** нельзя ответить «сколько закупить в следующем месяце».
