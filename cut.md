# Что не входит в проект

## 1. Реальное обогащение из внешних API

**Что:** VIN-декодер, каталоги применимости, марки и модели авто.  
**Почему нет:** платные ключи и отдельный стек интеграций.  
**Цена ошибки:** нельзя построить отчёт «продажи по маркам автомобилей». Режем только по товару, бренду запчасти, магазину и региону сети.

## 2. Возвраты и брак

**Что:** `fact_returns` и метрика «оборот без возвратов».  
**Почему нет:** в сырье возвратов нет, искусственные строки исказят бизнес-смысл.  
**Цена ошибки:** главная метрика — валовой оборот `SUM(fact_sales.total_amount)`, не чистая выручка.

## 3. Кластер ClickHouse, шардирование, репликация

**Что:** ReplicatedMergeTree и распределённые таблицы.  
**Почему нет:** учебный стенд — один узел в Docker; кластер требует несколько машин.  
**Цена ошибки:** нет проверки отказоустойчивости. Для объёма сети (65 000 строк продаж) один узел достаточен.

## 4. Стриминг через Kafka

**Что:** потоковая загрузка «источник → Kafka → ClickHouse».  
**Почему нет:** задание — батчевая загрузка из файлов.  
**Цена ошибки:** данные обновляются пакетом, не в реальном времени. Повторный пакет перезаписывает витрину целиком.

## 5. ML-модель прогноза спроса

**Что:** предсказание спроса по SKU и магазину.  
**Почему нет:** тема курса — OLAP, не машинное обучение.  
**Цена ошибки:** нельзя ответить «сколько закупить в следующем месяце», можно только смотреть историю.
