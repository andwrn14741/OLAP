# З09. Сводка под график

Виджет на дашборде — линия «Оборот по дням и магазинам». На экране одна линия оборота сети по дням: запрос виджета сворачивает магазины, иначе 41 точка × 365 дней упирается в лимит строк Metabase. Разрез по магазину остаётся в таблице сводки.

Одна строка сводки `mart_revenue_day_store` = один день × один магазин. В строке уже лежат `revenue` и `quantity`. Это не grain факта: факт — позиция заказа, сводка — готовая сумма дня магазина.

`revenue` считается как `sum(fact_sales.total_amount)`, то есть той же формулой, что `sql/canonical_metric.sql`. Эталон по-прежнему считается по детальной таблице, не по сводке.

Пересчёт после повторной загрузки: `bash etl/rebuild_mart.sh`. Скрипт очищает сводку и заполняет её заново из `fact_sales`. Сумма `revenue` сводки обязана совпасть с `sum(total_amount)` факта; запрос сверки стоит в конце `sql/mart_clickhouse.sql`.

Прогон 2026-10-04: `mart_revenue = 788793643`, `fact_revenue = 788793643`, `sums_match = 1`.
