# Паспорт витрины (P02 / зачёт)

ФИО: Ворон Андрей Дмитриевич · Дата: 2026-10-04 · Домен: федеральная сеть магазинов автозапчастей «АвтоДеталь»

## 1. Бизнес-цель витрины (1–2 предложения)

Витрина собирает продажи, закупки и отгрузки сети «АвтоДеталь»
(41 магазин в 8 регионах), чтобы считать оборот по регионам и месяцам,
находить топ товаров и оценивать стоимость доставки по перевозчикам.

## 2. Grain (одна фраза)

Одна строка `fact_sales` = одна позиция заказа в конкретном магазине сети
(товар × количество × цена за штуку × сумма).

## 3. Fact-таблица(ы)

| Имя | Grain | Примечание |
|-----|-------|------------|
| `fact_sales` | позиция заказа в магазине | главный факт, 65 000 строк из `sales.csv` |
| `fact_purchases` | позиция закупки у поставщика | 6 500 строк из `purchases.csv` |
| `fact_logistics` | отгрузка заказа | 58 484 строки из `logistics.csv`; около 10% заказов — самовывоз и в факт не попадают |

## 4. Меры

| Мера | Тип (sum ok / нет) | Определение |
|------|--------------------|-------------|
| `quantity` | sum ok | количество штук в позиции |
| `total_amount` (продажи) | sum ok | оборот позиции = quantity × price_per_unit |
| `total_amount` (закупки) | sum ok | закупочная стоимость позиции |
| `total_amount` (доставка) | sum ok | стоимость доставки по отгрузке |
| `price_per_unit` | **нет** | средняя цена = SUM(total_amount) / SUM(quantity), не AVG |

## 5. Измерения

| Dim | Ключ | Важные атрибуты | SCD1 / SCD2 / нет |
|-----|------|-----------------|-------------------|
| `dim_product` | product_id | product_name, category, brand | **SCD2** — история категории; реализация на З06 |
| `dim_store` | store_id | store_name, city, region, store_format | SCD1 |
| `dim_customer` | customer_id | customer_name, customer_type, region | SCD1 |
| `dim_supplier` | supplier_id | supplier_name, country | SCD1 |
| `dim_carrier` | carrier | delivery_type | SCD1 |
| `dim_date` | date_id | year, month, day, weekday, quarter | нет (календарь статичен) |

## 6. Три бизнес-вопроса

1. Какой оборот по регионам сети за каждый месяц 2025 года?
2. Топ-10 товаров по количеству проданных штук за год?
3. Средняя стоимость доставки по перевозчикам и доля самовывоза?

## 7. Эталонный SQL одной метрики

```sql
-- Главная метрика: валовой оборот сети
SELECT SUM(total_amount) AS revenue
FROM fact_sales;
```

**Зафиксированное число:** 788 793 643.00

## 8. Риски / cut

Возвраты не учтены: в сырье их нет, метрика «оборот» — валовая.
История категории товара (`dim_product`) заявлена как SCD2; до З06 в витрине лежит только текущая версия.
Обогащение по VIN и маркам авто, кластер ClickHouse, Kafka и ML вне проекта — см. `cut.md`.
