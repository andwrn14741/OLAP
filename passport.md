# Паспорт витрины (P02 / зачёт)

ФИО: Ворон Андрей Дмитриевич · Дата: 2026-09-24 · Домен: розничная продажа автомобильных запчастей

## 1. Бизнес-цель витрины (1–2 предложения)

Витрина собирает продажи, закупки и отгрузки магазина автозапчастей,
чтобы считать оборот по категориям и месяцам, находить топ-товары
и оценивать стоимость доставки по перевозчикам.

## 2. Grain (одна фраза)

Одна строка `fact_sales` = одна позиция в заказе (товар × количество × цена за штуку × сумма).

## 3. Fact-таблица(ы)

| Имя | Grain | Примечание |
|-----|-------|------------|
| `fact_sales` | позиция в заказе | главный факт, 20 000 строк из `sales.csv` |
| `fact_purchases` | позиция в закупке | 2 000 строк из `purchases.csv` |
| `fact_logistics` | отгрузка по заказу | ~18 000 строк из `logistics.csv`; ~10% заказов — самовывоз |

## 4. Меры

| Мера | Тип (sum ok / нет) | Определение |
|------|--------------------|-------------|
| `quantity` | sum ok | количество штук в позиции |
| `total_amount` (продажи) | sum ok | оборот по позиции = quantity × price_per_unit |
| `total_amount` (закупки) | sum ok | закупочная стоимость позиции |
| `total_amount` (доставка) | sum ok | стоимость доставки по отгрузке |
| `price_per_unit` | **нет** | средняя цена = SUM(total_amount)/SUM(quantity), не AVG |

## 5. Измерения

## 6. Три бизнес-вопроса

1. Какой оборот по категориям товаров за каждый месяц 2025 года?
2. Топ-10 товаров по количеству проданных штук за год?
3. Средняя стоимость доставки по перевозчикам и доля самовывоза?
